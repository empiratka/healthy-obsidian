# Time-Restricted Fasting
Ограниченное по времени питание

Type: [[behavior]]

Description:
Pattern in which food intake is restricted to a specific daily time window.

Variants:
- 16-hour fast / 8-hour eating window
- 20-hour fast / 4-hour eating window

Associated effects:
- may be used in patients with [[condition_diabetes_type2|T2DM]] and [[condition_obesity|obesity]][^1]

[^1]: [[Time-Restricted Feeding and Intermittent Fasting as Preventive Therapeutics]]
