В среднем стоит употреблять 125 g (100–150) per day цельно зерновых для увеличения здоровых лет жизни[^1] 
- это где-то 2-3 ст.л. крупы в сухом виде

## Представители цельнозерновых

| Псевдозерновые | Зерновые      | Зерновые с глютеном            |
| -------------- | ------------- | ------------------------------ |
| Гречиха        | Овес\*        | Пшеница (полба, булгур, манка) |
| Киноа          | Пшено (просо) | Рожь                           |
| Амарант        | Рис           | Ячмень (перловка)              |
|                | Кукуруза      |                                |
|                | ...           |                                |
\* - *овес не содержит глютен, но на производстве часто попадает в состав из других круп*
