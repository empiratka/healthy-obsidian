Способность материальных тел проводить тепловую энергию от более нагретых частей к менее нагретым частям.

Чем ниже, тем меньше передача тепла, и образуются горячие и холодные зоны

| Материал          | Теплопроводность (Вт/м·K) |
| ----------------- | ------------------------- |
| Медь              | 390–400                   |
| Алюминий          | 205–237                   |
| Чугун             | 50–60                     |
| Нержавеющая сталь | 14–16                     |
