Количество теплоты, поглощаемой (выделяемой) телом в процессе нагревания.

Чем выше удельная теплоемкость, тем хуже материал удерживает тепло и меньше тепла ему нужно для разогрева.

Высокая теплоемкость = может удерживать много тепла, не сильно охлаждаясь при добавлении холодных ингредиентов

| Материал       | Удельная теплоемкость на вес (Дж/г·K) |
| -------------- | ------------------------------------- |
| **Алюминий**   | 0.897                                 |
| **Медь**       | 0.385                                 |
| **Нержавейка** | 0.500                                 |
| **Чугун**      | 0.500                                 |
