Упражнения обычно помогают только при ложной [[Близорукость]], вызванной спазмом мышц[^1][^2]

Есть 3 вида упражнений
- [[Упражнения для аккомодации]]
- [[Массаж акупунктурных точек]]
- [[Йогические упражнения глаз]]
