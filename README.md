## Ресурсы
- Статьи стараюсь указывать в сносках в заметках. Могут быть опечатки 
	- Увы я не успеваю все перепроверить, часто просто доверяю источнику, но время расставит точки над И.
- Беру материалы из разных источников, но преобладает информациях от Макса Погорелова. Я конспектировала его [YouTube](https://www.youtube.com/@Max_Pogorely) видео и его [статьи](https://moveat.expert/stati/)
	- Очень благодарна проекту Макса. В отличие от других источников он реально полагается на научные исследования и метаанализы (исследование нескольких исследований по одной тематике). 
		- Такой подход исключает выбросы, на которых паразитирует большинство источников

## Как использовать
- Читать текст можно и через github, но картинки не будут отображаться в тексте. 
	- В картинках преимущественно графики и изображение продукта. Основное Представлено в тексте, так что не страшно.
- Просмотр через [Obsidian](https://obsidian.md/), для этого надо:
	1. Установить приложение - https://obsidian.md/download
	2. Установить git - https://git-scm.com/downloads
	3. Ввести в консоль в своей папочке `git clone https://github.com/shlegelal/healthy.git`
	4. Открыть проект в Obsidian при помощи графического интерфейса
	5. Возможно придется установить некоторые расширения. Приложение должно подсказать при открытии проекта
	6. Наслаждайтесь картинками и ссылками :)
		- Возможно придется поизучать приложение, потому что там много плюшек, в частности ссылки и граф (для этого нажмите `ctrl + G`)

## Структура проекта
- **Res** - папка с вспомогательными файлами
	- **Files** хранит картинки из заметок. Увы в github они не будут отображаться
	- **Templates** - заготовки заметок. Использовать при создании новых заметок
- **Project** - корень проекта
	- **0Справка** - всякие условности, которые важны для понимания материала
	- **1Питание** - ТУТ ОСНОВНОЕ МЯСО :)
	- **2Спорт**
	- **3Сон**
	- **4Состояние организма** - болезни и приколы организма
	- **5Части тела** - файлы могут быть пустыми (они нужны для связей)
	- **6Измерения** - анализы или другие численные метрики
	- **Другое**
		- **Мое мнение** - тут просто мои заметки, практические подсчеты и всякие уловки
		- **Специфическое** - название говорит само за себя
### Связи
- Так как информация сильно связана идеально подошел метод [Зеттелькастен](https://en.wikipedia.org/wiki/Zettelkasten).
	- Благодаря нему каждая заметка атомарна и связанна с несколькими другими.
- Связи - это текст в квадратных скобках `[[README.md]]`. 
	- В Приложении Obsidian с ними очень удобно работать.
